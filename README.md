# CN6005-Artificial-Intelligence-Exercises
This repository brings together my artificial intelligence exercises in one place. Its purpose is to document each experiment from start to finish: the problem, the approach, the results and what they show.

Each exercise has its own folder with a short report covering the aim, method, results and conclusions. An appendix subfolder holds the full notebook, an HTML copy and any screenshots, so every result can be traced back to the code that produced it.

The exercises focus on comparing methods fairly, by keeping settings consistent, evaluating with clear metrics and explaining model behaviour rather than only reporting accuracy.
